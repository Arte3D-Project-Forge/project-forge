# PROJECT FORGE BIBLE

Version: 1.0

## Visão

Project Forge é um sistema operacional de desenvolvimento de jogos baseado em IA.

Objetivo:

Permitir que pequenos estúdios e desenvolvedores independentes criem jogos completos através de agentes inteligentes.

---

# Missão

Transformar uma ideia de jogo em produção:

CONCEPT
↓
DESIGN
↓
ART
↓
AUDIO
↓
CODE
↓
BUILD
↓
RELEASE


---

# Princípio principal

Engine Independent.

O Project Forge não pertence a uma engine.

Ele deve suportar:

- Godot
- Unity
- Unreal Engine
- Engines futuras


---

# Público

- Indie developers
- Pequenos estúdios
- Criadores usando IA
- Designers sem programação


---

# Visão futura

Criar uma fábrica completa de produção de jogos utilizando agentes IA.
