# DEVELOPMENT RULES


## Código

Sempre entregar:

arquivo completo

Exemplo:

app/services/project_manager.py


Nunca:

"adicione estas linhas"


---

## Organização

Manter:

app/

models/

services/

ui/

modules/

data/


---

## Testes

Toda implementação deve possuir:

1. teste
2. validação
3. documentação


---

## Evitar

- código duplicado
- arquivos gigantes
- dependências sem necessidade
- soluções temporárias
